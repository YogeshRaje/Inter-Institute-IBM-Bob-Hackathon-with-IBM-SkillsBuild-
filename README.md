# Inter-Institute IBM Bob Hackathon with IBM SkillsBuild 🚀

> **Theme:** *Build for Bengaluru • Go Beyond the Vibe*  
> **Dates:** 17–18 November 2026  
> **Host Campus:** Sambhram Institute of Technology, Bengaluru  
> **Organizers:** Sambhram Institute of Technology in collaboration with Edunet Foundation & IBM SkillsBuild  

---

## 🌐 Overview

The **Inter-Institute IBM Bob Hackathon with IBM SkillsBuild** is an elite 2-day live innovation sprint uniting 20 selected student engineering teams (10 from Sambhram Institute of Technology + 10 from premier partner engineering colleges across Bengaluru).

Participants leverage **IBM Bob**, **IBM Granite LLMs**, and **IBM Cloud** to architect scalable, multi-agent AI solutions addressing critical civic and municipal friction points across Bengaluru and Karnataka.

---

## 🏛️ The Three City Impact Pillars

Grounded in the TechGig *Build for Bengaluru* mission, all projects align with three transformative community pillars:

1. 🚦 **A City That Moves Better** — Dynamic traffic bottleneck forecasting, multi-modal transit synchronization, pothole detection, and pedestrian safety.
2. 💼 **Creates More Opportunities** — Skill-to-job matching, MSME compliance automation, artisan/farmer direct marketplaces, and gig worker safety nets.
3. 🌱 **Cares for Its Communities** — Hyperlocal bilingual health triage, automated municipal grievance routing, clean water monitoring, and climate resilience.

---

## ⚙️ Enterprise Technology Stack

- **IBM Bob** — Next-generation conversational agentic AI developer tool for workflow orchestration, tool execution, and multi-agent coordination.
- **IBM Granite LLMs** — Open foundation models engineered for enterprise accuracy, code synthesis, and explainable inference.
- **IBM Cloud & watsonx** — Enterprise cloud foundation for secure API endpoints, model serving, and compute deployment.
- **Agentic AI Architecture** — Autonomous agent delegation, memory management, tool retrieval, and verification loops.

## 📤 4 Core Submission Deliverables

As evaluated by two independent IBM Jury Panels (7-minute pitch + 3-minute Q&A):

| # | Deliverable | Description |
|---|---|---|
| **01** | **Target Problem & Beneficiaries** | Concrete identification of high-friction civic bottlenecks in Bengaluru with defined beneficiary personas. |
| **02** | **Functional Working Prototype** | Verified live software prototype powered by IBM Bob and IBM Cloud executing dynamic agentic tool calls. |
| **03** | **The Bob Story & Architecture** | Detailed walkthrough illustrating multi-agent coordination, prompt iteration, and tool-calling workflows. |
| **04** | **Measurable Community Impact & Code** | Verifiable civic outcome projections alongside a clean, well-documented public GitHub repository. |

### How to Run Locally

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/YogeshRaje/Inter-Institute-IBM-Bob-Hackathon-with-IBM-SkillsBuild-.git
cd Inter-Institute-IBM-Bob-Hackathon-with-IBM-SkillsBuild-
# Open index.html directly or serve with python:
python -m http.server 8080
```

Visit `http://localhost:8080` in your browser.
